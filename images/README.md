# 画像差し替えガイド

LP（`index.html`）は下記ファイル名の画像をこのフォルダに置くと自動で表示されます。
未配置の画像はベージュのプレースホルダー（ファイル名表示）になります。
公式サイト / 公式Instagram（@harika_kogao）の素材を、下記の推奨比率で書き出して配置してください。

| ファイル名 | 用途 | 推奨比率 |
|---|---|---|
| fv.jpg | ファーストビュー背景（施術中・女性の横顔など） | 縦長 3:4〜9:16（PCは中央トリミング） |
| campaign.jpg | キャンペーン枠の施術イメージ | 4:3 |
| reason-01〜04.jpg | 選ばれる理由①〜④ | 16:8 |
| w-01〜03.jpg | W施術（電気美容鍼 / 小顔矯正 / ヘッドスパ） | 1:1 |
| insta-01〜06.jpg | インフルエンサー来店投稿 | 4:5 |
| clinic.jpg | 東京駒込皮フ科クリニック | 4:3 |
| staff-01〜03.jpg | スタッフ写真（顔出し可の方） | 4:5 |
| ba-01-before.jpg 〜 ba-10-after.jpg | Before / After（10組） | 3:4 |
| store-01〜10.jpg | 店舗写真（01はワイド表示） | 1:1（01のみ 2:1） |

テキストの差し替えが必要な箇所：
- スタッフ紹介：〔ニックネーム〕〔趣味〕〔お客様へ一言〕
- インフルエンサー：`@influencer_01` などのアカウント名・コメント
